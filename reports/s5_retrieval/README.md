在这批 Validation 题上，选中 M1 相对 B0 的 nDCG@10 与 Recall@10 CI 下界大于 0；相对 B1 的四项 CI 都跨 0，不能据此宣称稳定优于 Dense。M1 的 p50 明显高于 B1，当前 SQLite BM25 是可复现研究实现，尚未进行服务化性能优化。
