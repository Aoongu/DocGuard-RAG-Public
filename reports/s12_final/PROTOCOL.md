# S12 最终评测执行协议

S12 只在冻结的 `s4-golden-v1` Test 集上执行一次。Test 共 60 题，已经完成双轮人工复核；其 SHA-256、题目内容摘要、方法参数、run ID、输出目录和上游制品哈希均由 `configs/evaluation/s12-final-v1.json` 固定。

## 固定执行顺序

1. B0：BM25。
2. B1：Dense。
3. M1：Dense + BM25 + RRF。
4. M2：M1 + Cross-Encoder。
5. B2：Dense + DeepSeek 生成。
6. M3：M2 + DeepSeek 生成，不启用拒答决策。
7. M4：完整检索、重排、生成前拒答和生成后引用校验。
8. M4 去版本过滤。
9. M4 去引用验证。

六项消融不制造重复实验：去 BM25、去 Dense、去 Cross-Encoder、去拒答分别复用 B1、B0、M1、M3 的原始结果哈希；另外两项使用各自唯一的 M4 消融运行。

## 一次性规则

- 自动重试固定为 0。
- 成功行和失败行只要已写入，后续恢复都必须跳过。
- 进程中断时，只能继续尚未产生任何记录的 question ID。
- 每个方法只能使用预注册 run ID 和输出目录；禁止命令行覆盖。
- 复现实验必须使用新协议、新 run ID 和新目录，不能覆盖本轮制品。
- Test 结果一旦生成或查看，不得再调整参数、阈值、Prompt、方法选择或样本。

## 预检密封

正式执行前，`scripts/prepare_s12.py` 必须在干净提交上完成一次只读预检。预检验证冻结输入哈希、双轮复核状态、两个模型、两个 tokenizer、Dense/BM25 索引、用户级 DeepSeek 凭据存在性，以及九个正式输出目录均不存在。凭据值不会写入日志或制品。

预检只生成 `reports/s12_final/preflight.json`，其中 `results_viewed=false`。预检不运行检索、不调用生成 API，也不读取任何 Test 结果。

## 固定执行入口

正式执行只允许使用 `scripts/run_s12.ps1`：`offline` 固定运行 B0→B1→M1→M2，`online` 固定运行 B2→M3→M4→去版本过滤→去引用验证，`all` 依次执行两组。入口会核对 seal 绑定的 Git commit，并且只允许 seal、执行账本和 `reports/s12_final/raw/` 出现在工作树变更中。

每个方法启动前先原子写入 `running` 账本。若进程中断，只能恢复同一方法；完成后账本固定结果与汇总 SHA-256、60 题计数、成功/失败数、费用统计和服务端模型身份。已完成方法不能再次执行，后续方法不能越序执行。

## 结果边界

所有汇总均以固定 60 题为总分母，同时单列可评分数、不可评分数、生成失败率和多标签失败原因。人工平均分只在可评分样本上计算；Judge 一致率只在 Judge 与人工结果都完整的可评分交集上计算。任何失败均原样保留，不补跑、不换题、不从分母中删除。
