# 文档发现与知识库导入

用户填写产品、可选版本和需求，选择详细使用文档、API参考、快速入门或具体主题。Agent 在工具合同和预算内搜索、阅读、跟随真实导航并核查候选来源；用户确认后启动导入。

集合导入仅沿批准的同源目录收集可达静态HTML页面，最多1000页、512MiB，每次收集最多1800秒。目录外、其他版本、PDF与压缩包不会被当作该集合正文。原始HTML与SHA-256保留；任一抓取/切块/索引失败都不会发布部分结果。

进度依次显示收集页面、解析切块、关键词索引、向量编码和发布；编码按批次显示真实分块计数。失败导入可以复用缓存重试；搜索重新提交创建新任务，原日志保留。

每个知识库使用自己的快照与索引，检索流程为 E5 Dense + BM25 → RRF → BGE Cross-Encoder，证据检查可查看各路排名、分数和来源。生成支持 answer/refuse/clarify，引用验证只检查结构与已提供证据的对应，不等同于语义蕴含证明。

新领域的拒答阈值需要独立标注与校准，当前未自动复用PostgreSQL阈值。来源模型判断需要用户确认；同站链接关系并不构成独立的官方所有权证明。新增工程夹具验证流程正确性，不构成真实搜索准确率评测。

API入口：`/api/v1/discovery/tasks`、`/api/v1/imports/{job_id}`、`/api/v1/knowledge-bases`。技术问答结果保留在会话中，引用可跳转证据检查，回答完成后定位至结果。
